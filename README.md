# KEN_model_public
## Public releases of the KAUST Economy-Nature (KEN) model, developed and maintained at the KAUST Systems Science Lab

## Remark on current versions
The first version of the KEN model will go live soon, upon the publication of the first KEN working paper:
“Transformation dynamics of an energy-rich and water-scarce economy in the Middle East”, 
co-authored by Michael Miess, Ansir Ilyas, Dan Wang, Asjad Naqvi, and Yoshihide Wada.
